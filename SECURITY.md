# Reporting a security problem

Please report security problems privately, not in a public issue.

Use GitHub's private reporting on this repository: **Security → Report a vulnerability**. Include the version (see `VERSION`), what you did, what happened, and what an attacker could gain.

You will get an acknowledgement within a few days. Please give us a reasonable time to fix a problem before you disclose it.

In scope: the three HAI apps, the editor and migration pages, and the web endpoints the apps expose on the hub. Out of scope: Hubitat's own firmware and other apps.
