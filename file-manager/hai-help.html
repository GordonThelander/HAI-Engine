HAI is a rule engine for Hubitat, an alternative to Rule Machine, built so a rule can be read, checked and trusted before it runs. Key features
• A modern, interactive rule editor: drag and drop steps, cut, copy and paste between rules, undo, search, every step in plain English, and live device values beside each condition.
• Checked before it runs: missing devices, commands a device does not offer and steps that can never run are found when you save.
• Simulate a rule, and see exactly what differs from the copy on the hub before you put it there.
• Backups and restore: a nightly copy of every rule, compared and restored from the editor.
• RM migration (optional): test copies of your Rule Machine rules in HAI, switch them over one at a time, and switch back whenever you like.
• AI Rule Assistant (optional): describe a rule in your own words and Claude drafts it, on your own key, with a spending limit; drafts go through the same checks.
• Run rules from anywhere: a dashboard tile, a phone shortcut, another hub or another app can start a rule or set a value, through a web address HAI gives you. Benefits
• Faults are caught at the desk, not discovered when a light fails to come on.
• Rules are explained in plain speak.
• Controlled testing and migration from Rule Machine, and back.
• HAI sends nothing off the hub except what your own rules ask for and, if you add an AI key, what you ask it to draft. User documents
